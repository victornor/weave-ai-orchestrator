AGENTCONDUCTOR
Design spec · v0.1 · dark-first

Control plane for AI coding agents

A spec canvas: token sheet, component sheet, then every screen as phone and desktop frames side by side, with flow arrows for the scenario paths. Dark is the designed theme; light is specified in tokens and shown on the screens where the two diverge.

ORGANISING IDEA
Every screen answers, in order: what is happening · does it need me · what do I do about it. Layouts put state first, ownership second, action third.
COLOUR STANCE
The chrome is greyscale. Colour is spent almost entirely on the nine status tokens, so a coloured pixel always means state. The accent appears only on primary actions and focus.
FIDELITY
Pass 1: all fourteen screens at structural fidelity, real type and real density. Pass 2 deepens whichever ones you pick.
