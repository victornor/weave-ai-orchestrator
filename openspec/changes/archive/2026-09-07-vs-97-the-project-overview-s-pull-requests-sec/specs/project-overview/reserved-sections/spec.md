## REMOVED Requirements

### Requirement: The overview reserves a Pull requests section

**Reason**: The section is no longer reserved — it lists the project's pull requests. What it shows,
including what it says when a project has no pull requests and when it has no forge, is now
specified by `project-overview/pull-requests`. Keeping a requirement that the section shows no pull
request would contradict the section that now does.

**Migration**: None. The section keeps its name, its key and its place in the overview's published
order; only its content changes. The reserved History section and the contract every section is
rendered against are untouched.
