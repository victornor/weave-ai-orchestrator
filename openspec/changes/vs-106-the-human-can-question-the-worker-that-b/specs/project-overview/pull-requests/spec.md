## ADDED Requirements

### Requirement: A pull request's ticket link opens on its conversation with the worker

Opening a pull request's ticket from the project overview SHALL land the human directly on that
ticket's conversation with the worker that produced it, rather than on a view the human must
navigate away from to find it.

#### Scenario: Opening a pull request's ticket

- **WHEN** the human opens a pull request's ticket link from the project overview
- **THEN** the ticket opens on its conversation with the worker that produced the pull request
